# Sistema Web para Gerenciamento de Encomendas Artísticas

Projeto acadêmico desenvolvido na disciplina de Projeto de Software, com o objetivo de criar um sistema web para auxiliar na organização e no gerenciamento de encomendas artísticas.

## Objetivo

Facilitar o controle de clientes, encomendas, prazos, referências e pagamentos, centralizando as informações em um único ambiente.

## Funcionalidades previstas

- Cadastro e consulta de clientes.
- Cadastro e gerenciamento de encomendas artísticas.
- Acompanhamento de prazos e status de produção.
- Organização de referências das encomendas.
- Controle de pagamentos.

## Tecnologias utilizadas

- Python
- Flask 3.x
- HTML5
- CSS3
- PostgreSQL

## Arquitetura

O sistema utiliza arquitetura monolítica em camadas, organizando as responsabilidades da aplicação para facilitar sua manutenção e evolução.
